DeFi DNA Risk Intelligence by cp0x

DeFi DNA is an open-source, neutral aggregator of DeFi risk intelligence from cp0x. It shows what each risk feed publishes about Ethereum mainnet protocols, with the original source and assessment date.

  • Browse coverage one protocol version at a time.
  • See total value locked and incidents recorded by DefiLlama on the dashboard.
  • Open a protocol to compare the feeds' published assessments side by side.

View the source code on GitHub and learn about cp0x.
