What the columns mean

One protocol, separate versions

Rows group related versions for navigation. Expand one to read each version's records; their values are never combined.

Source date and collection date

“Source assessed” is when the provider dated its assessment. “Collected” is when the project last retrieved that entry. An older assessment is not a failed collection.

No cp0x risk rating

Each provider has its own subject and scale. This directory reports coverage and shows the original records without a shared grade or ranking.
