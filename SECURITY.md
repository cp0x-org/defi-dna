# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions or pull requests.

Report them privately instead:

- security contact: admin@cp0x.com
- or, if enabled for this repository, via GitHub's
  [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

Please include a description of the issue, the steps to reproduce it and the
affected version or commit. You will receive an acknowledgement, and we will
keep you informed about the progress towards a fix.

Data accuracy problems — a misquoted verdict, a wrong source link, a stale entry
— are **not** security issues. Report those as a normal public issue or pull
request, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Supported versions

The project is in early development; only the `main` branch is supported.
